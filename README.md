# تطبيق القضارف | دليل الولاية

هذا مشروع Flutter مبدئي جاهز للتطوير.

## ماذا يعمل الآن؟
- الصفحة الرئيسية.
- البحث في الأماكن.
- تصنيفات: فنادق، مطاعم وكافيهات، صحة، أسواق، وقود، بنوك، مواصلات، خدمات، حكومي، أماكن حيوية وسياحية.
- إضافة مكان أو خدمة من داخل التطبيق.
- إضافة صورة للمكان.
- رقم هاتف والاتصال المباشر.
- إحداثيات وفتح الاتجاهات في Google Maps.
- المفضلة.
- حفظ البيانات محلياً على الجهاز.

## التشغيل
1. ثبّت Flutter وAndroid Studio.
2. افتح مجلد المشروع.
3. نفّذ:
   flutter pub get
   flutter run

## مهم قبل Google Play
النسخة الحالية تحفظ البيانات محلياً، لذلك المكان الذي تضيفه يظهر على نفس الجهاز فقط.
للنسخة العامة نحتاج المرحلة التالية: ربط التطبيق بقاعدة بيانات سحابية + لوحة إدارة خاصة بك + تسجيل دخول للمشرف + رفع الصور للسحابة.
ولا ينبغي نشر نسخة عامة تسمح لأي شخص بإضافة أو حذف البيانات بدون صلاحيات.
